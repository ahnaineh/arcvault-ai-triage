# Workflow demo

[Watch the 2:15 demo](arcvault-demo.mp4) · [Download the five JSON outputs](narrated-five-outputs.json)

The demo submits a login request through the webhook and shows its completed analysis. It then walks through the other four assessment results, processed earlier through the same application. All five use real model responses.

The invoice goes to Billing with an apparent $260 difference and explicit comparison assumptions. The multi-user dashboard outage goes to Human Review. Each result includes its category, priority, confidence, summary, identifiers, and destination, and can be exported as JSON.

Narration uses an AI-generated voice. The recording is edited for length and readability.
